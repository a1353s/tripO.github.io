# 背景动图素材

切换「详细时间表」天数时，整页背景切换对应地点的 **3 秒循环动图**（WebP）。  
切换瞬间先显示静图，再叠加上动图。

静图 / 动图会写入浏览器 **Cache Storage**（`tripo-bg-v1`），并在内存中保留 blob URL：  
同一会话切换日期不再重复下载；下次打开页面也会优先从本地缓存读取。

## 文件命名（同名覆盖即可替换）

| 文件 | 对应天数 | 说明 |
|------|----------|------|
| `yangshuo.webp` / `.jpg` | D1–D2 | 阳朔 |
| `longji.webp` / `.jpg` | D3–D4 | 龙脊梯田 |
| `guilin.webp` / `.jpg` | D5 | 桂林象鼻山 |
| `beihai.webp` / `.jpg` | D6–D9 | 北海银滩 |

- `.jpg`：切换瞬间静图  
- `.webp`：约 3 秒循环动图  

建议：动图宽度约 720px、时长 3 秒、单文件尽量 &lt;1.5MB。页面用 `object-fit: cover`，不会拉伸变形。

替换时用同名文件覆盖即可，无需改代码。若你更新了线上资源文件，用户可能仍看到旧缓存，可改 `bg-media.js` 里的 `CACHE_NAME`（如 `tripo-bg-v2`）强制刷新。
