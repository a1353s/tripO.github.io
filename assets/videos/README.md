# 背景动图素材

切换「详细时间表」天数时，整页背景切换对应地点的 **3 秒循环动图**（WebP）。  
使用图片而非 `<video>`，避免手机端调起系统播放器，也更利于 GitHub Pages 加载。

## 文件命名（同名覆盖即可替换）

| 文件 | 对应天数 | 说明 |
|------|----------|------|
| `yangshuo.webp` / `.jpg` | D1–D2 | 阳朔 |
| `longji.webp` / `.jpg` | D3–D4 | 龙脊梯田 |
| `guilin.webp` / `.jpg` | D5 | 桂林象鼻山 |
| `beihai.webp` / `.jpg` | D6–D9 | 北海银滩 |

- `.webp`：约 3 秒循环动图（背景用）  
- `.jpg`：静图占位 / `prefers-reduced-motion` 降级  

建议：动图宽度约 720px、时长 3 秒、单文件尽量 &lt;1.5MB。页面用 `object-fit: cover`，不会拉伸变形。

## 当前来源简述

- 阳朔 / 龙脊：原风光素材转 3s 动图  
- 桂林：两江四湖·象山景区相关画面转 3s 动图  
- 北海：银滩官网风光转 3s 动图  

替换时用同名 `.webp`（及可选 `.jpg`）覆盖即可，无需改代码。
