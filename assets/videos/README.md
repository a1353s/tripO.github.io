# 背景视频素材

切换「详细时间表」天数时，整页背景会播放对应地点短视频（取前约 5 秒循环）。

## 文件命名（同名覆盖即可替换）

| 文件 | 对应天数 | 说明 |
|------|----------|------|
| `yangshuo.mp4` / `.jpg` | D1–D2 | 阳朔 |
| `longji.mp4` / `.jpg` | D3–D4 | 龙脊梯田 |
| `guilin.mp4` / `.jpg` | D5 | 桂林象鼻山 |
| `beihai.mp4` / `.jpg` | D6–D9 | 北海银滩 |

建议：H.264 mp4，片源 ≥5 秒，单文件尽量 &lt;5MB；比例不限（页面用 `object-fit: cover` 裁切铺满，不会拉伸变形）。

## 当前国内来源

- **桂林 / 象鼻山**：截取自桂林「两江四湖·象山景区」官网宣传片（优酷嵌入片源），选取象鼻山相关镜头片段。  
  参考：https://www.glljsh.com/post/13587.html
- **北海 / 银滩**：基于北海银滩国家级旅游度假区官网风光摄影实景图制作短视频。  
  参考：https://www.bhyintan.com/

你剪辑好自己的视频后，用同名文件覆盖本目录即可，无需改代码。

国内素材站（爱给网 / 觅知网 / 包图网等）也有「象鼻山」「银滩」成片，通常需登录或 VIP 后手动下载再覆盖。
